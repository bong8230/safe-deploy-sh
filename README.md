# safe-deploy-sh

개발서버에서 운영서버로 파일을 반영하는 **rsync 기반 Bash 배포 스크립트**입니다.
손으로 복사하던 운영 반영을 "미리 보고, 골라서, 백업한 뒤, 기록을 남기며" 하도록 만든 도구입니다.

> 실무에서 운영 중인 배포 스크립트의 설계 아이디어를 바탕으로 **처음부터 새로 작성한 공개용 버전**입니다.
> 회사 코드, 서버 정보, 경로는 포함하지 않습니다.

## 배포 흐름

```
설정 로드 → 접속 IP 확인 → dry-run으로 변경·삭제 후보 산출 → 파일 선택(select 모드)
  → 미리보기 → 환경명 입력 확인 → (삭제 시) DELETE 입력 확인
  → 대상 서버 백업 + 백업 검증 → 최종 y/n → 반영 → 상세·요약 로그 기록
```

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 두 가지 모드 | `select`: 변경 파일 중 번호로 골라 반영(삭제 없음) · `full`: 원본과 동일하게 동기화(삭제 포함) |
| 후보 산출 | `rsync --dry-run --itemize-changes --checksum`으로 실제로 바뀐 파일만 목록화 |
| 번호 선택 | `all`, `3`, `1,3`, `2-5`, `1,3-5` 형식 지원, 잘못 입력하면 다시 묻기 |
| 백업 + 검증 | 반영 전 대상 서버의 기존 파일을 백업하고 `cmp`로 확인. 하나라도 실패하면 배포 중단 |
| 신규 파일 표시 | 대상에 없던 파일은 `[NEW]`로 표시, full 모드에서 비율이 높으면 경로 오류를 의심해 경고 |
| 다단계 확인 | 허용 IP 대역 검사, 환경명 입력, 삭제 시 `DELETE` 입력, 최종 y/n |
| 재시작 안내 | `.class`, 매퍼 XML처럼 지정한 패턴이 바뀌면 WAS 재시작 필요 안내 |
| 로그 | 배포 건별 상세 로그 + 월별 요약 로그(결과, 단계, 파일 목록, 실행 IP). 중단 시점의 단계도 기록 |
| 로그 정리 | 상세 로그는 보관 기간(기본 365일)이 지나면 삭제, 요약 로그는 유지 |

## 사용법

```sh
cp examples/deploy.conf.example prod2.conf   # 환경에 맞게 수정
./safe-deploy.sh -c prod2.conf -m select      # 골라서 반영
./safe-deploy.sh -c prod2.conf -m full        # 전체 동기화(삭제 포함)
```

`TARGET_HOST`를 비우면 `DST_DIR`을 로컬 폴더로 취급합니다. 서버 없이 동작을 시연하거나 테스트할 때 씁니다.

### 실행 예 (select 모드)

```
===== 변경 후보 (2) =====
  1) js/app.js
  2) js/feature.js
배포할 파일 (all / 1 / 1,3 / 2-5 / list / q): 1
===== 미리보기 =====
  >fc.t...... js/app.js
계속하려면 환경명 'PROD2'을(를) 입력하세요: PROD2
===== 백업: /home/deploy/backup/202610/PROD2_select_20261023_101500 =====
[SUMMARY] total=1 copied=1 new=0 failed=0
백업이 끝났습니다. 반영할까요? (y/n) y
배포 완료. 백업 위치: /home/deploy/backup/202610/PROD2_select_20261023_101500
```

## 테스트

로컬 폴더 두 개를 개발·운영 서버로 가정하고 시나리오를 끝까지 실행합니다. GitHub Actions에서 `shellcheck`과 함께 실행됩니다.

```sh
bash tests/run.sh
```

- select 모드: 고른 파일만 반영되고, 기존 파일이 백업되고, 요약 로그에 SUCCESS가 남는지
- full 모드: 추가·삭제가 반영되고, 삭제된 파일도 백업되는지
- 환경명을 틀리면 아무것도 바뀌지 않고 CONFIRM_FAIL이 기록되는지
- 허용되지 않은 접속 IP에서 실행이 차단되는지
- 번호 입력 형식이 틀리면 다시 묻는지

## 요구 사항

Bash 4 이상, rsync, ssh(원격 배포 시)
